# 星准 · Crosshair Desktop

Windows 独立桌面准星。按下并松开 Ctrl+Alt 即可显示 / 隐藏准星，切换不展开 Game Bar，不改变前台窗口焦点。此软件为本项目的独立实现。

## 使用

1. 双击 `CrosshairDesktop.exe`。默认准星显示在主屏幕中心。
2. 在“样式”中调整参数，左侧预览与屏幕准星实时更新。
   要使用自选图片，进入“图片准星”→“选择图片…”。可用滑块或数字设置缩放和透明度；点击“在屏幕上调整”，拖动图片移动位置，拖动右下角绿色手柄按原比例缩放。点击“完成图片调整”恢复鼠标穿透；隐藏状态下只在调整时临时显示，可按 Ctrl+Alt 固定显示。
3. 在“位置与快捷键”中选择显示器、设置像素偏移，或点击“拖动调整位置”。调整完成后点击“完成位置调整”，恢复鼠标穿透。
4. 默认同时按下再松开左侧 Ctrl+Alt，切换固定显示 / 隐藏；也可以使用窗口右上角的按钮。要更换快捷键，在“位置与快捷键”点击“录入快捷键…”，按下想用的单键或组合键并全部松开，点击“使用此快捷键”；选择“按下时触发”或“松开时触发（全部松开）”，最后点击“应用快捷键”。
5. 点击“收起到托盘”、最小化或关闭设置窗口后，准星仍在运行。单击托盘中的青绿色准星图标打开设置；右键可显示 / 隐藏、居中或退出。

如果右下角暂时看不到图标，点击任务栏的“显示隐藏的图标”（小箭头）查看。也可以在 Windows“设置 → 个性化 → 任务栏 → 其他系统托盘图标”中开启“星准”，让它直接显示在任务栏上。再次双击 `CrosshairDesktop.exe` 也能恢复已运行程序的设置窗口。

## 功能

- 十字、T 形与圆环准星；圆环模式使用半径，不使用十字间距。
- 自选图片准星：PNG、JPG / JPEG、BMP、GIF（首帧）；保留原图透明区域，建议使用透明 PNG。
- 图片缩放 1%–1000%、独立不透明度、屏幕拖动定位与右下角手柄缩放；保持比例和中心，屏幕图片单边最大 2048 像素。
- 图片导入后自动复制到软件旁的 `images` 文件夹；支持图片预设，重启后恢复图片、大小和位置。文件最大 20 MB，单边最大 8192 像素，总像素不超过 1600 万。
- 线条尺寸和粗细、正负间距、0.5 步长与小数输入；范围与原版相同。
- 中心点开关、方形 / 圆形中心点、独立点尺寸；点尺寸 0 时跟随线条粗细。
- 描边粗细和颜色，支持包含透明度的 `#AARRGGBB` 描边色；描边粗细 0 表示关闭。
- RGB 通道、十六进制颜色、选色器、常用颜色与不透明度。
- 像素对齐；Windows DPI 缩放与原始像素尺寸两种模式。
- 深色、浅色和复杂背景预览。
- 预设新建、覆盖和删除；最多保存 100 个。
- Murbong `MBCH-` 分享码导入 / 导出。
- Murbong 旧版 JSON 和本程序样式 JSON 导入 / 导出；支持剪贴板与文件。
- 当前 CS2 `CS...` 和旧版 `CSGO-...` 分享码导入，可选择游戏分辨率高度。
- 显示器选择、中心定位、水平 / 垂直像素偏移、拖动调整及方向键按钮微调。
- 直接录入全局键盘快捷键：支持单键、单独修饰键、Ctrl / Alt / Shift / Win 组合、功能键、方向键、空格、Tab、数字小键盘、符号键，以及多个普通键的组合（例如 Q+E）。
- 可选择按下触发或全部松开触发。按下模式在组合按齐时触发；松开模式在该组合全部按键松开后触发。长按和系统按键重复不会导致连续开关。
- 透明置顶、鼠标穿透、无激活显示、托盘操作与自动保存。
- 后台键盘输入接收：游戏在前台时也可识别实体键盘快捷键；录入和软件模拟按键使用独立兼容通道，避免重复开关。

录入期间暂停开关，由录入窗口自己的键盘消息接收按键；每次打开会清空历史录入状态，窗口失去焦点时会重置未完成的录入。取消录入会保留原快捷键。新录入的按键仍需要点击“应用快捷键”；触发方式及“允许同时按住其他键”选项在选择后立即生效并自动保存，无需再点应用。左侧“快速开关”显示当前生效的按键和触发方式，“填入默认 Ctrl+Alt”按钮可恢复默认组合供应用。

在“位置与快捷键”勾选“允许同时按住其他键（游戏移动时也能切换）”，即可在按住 W、Shift 等其他键时切换，设置立即生效。此设置同时适用于按下触发和松开触发；松开触发只等待快捷键本身全部松开，移动键可以继续按住。其他键在快捷键之前或之后按下都不会取消切换，也不会自行触发开关。重新录入快捷键时会保留该选项。旧设置默认关闭此选项，以保留原有匹配行为。

关闭上述选项时，含普通按键的快捷键允许其他普通键同时按住，但会排除额外的修饰键；仅修饰键的组合会排除所有额外按键。Ctrl+Alt 组合始终忽略 AltGr。正常运行时按键仍会传给游戏及前台软件，因此也可能触发它们已有的快捷键。Win+L、Ctrl+Alt+Delete 等系统保留组合无法接管。程序只保存设定的快捷键，不记录键入的文字。旧设置会保留原触发方式：仅修饰键在全部松开时触发，旧版带普通按键的组合在按下时触发。

若游戏位于前台时仍无法切换，在“位置与快捷键 → 游戏快捷键兼容”查看后台接收状态。如果游戏以管理员权限运行，可点击“以管理员权限重启”，在 Windows 权限提示中确认，使准星与游戏的权限保持一致。取消权限提示会保留原程序；重启前会保存设置。默认启动仍使用普通权限。

## 保存和迁移

全部设置和预设保存在软件旁的 `crosshair-settings.json`，修改后约半秒自动保存；`crosshair-settings.json.bak` 保存上一次完整设置。主设置损坏时会尝试恢复备份，并显示提示。

迁移时复制程序、设置文件以及 `images` 文件夹（如使用图片准星）。形状样式可通过分享码或“导出样式 JSON”单独分享；MBCH 和样式 JSON 不包含图片。图片模式中可使用左侧预设保存，切换回“样式”→“使用形状准星”可恢复原形状。替换图片或删除预设不会删除已复制的图片，以保留其他预设及备份对它的引用。程序不会自动读取商店应用的受隔离设置；要迁移原准星，使用原应用导出的 JSON 或分享码。

## 兼容范围

- Windows 10 / 11，x64，.NET Framework 4.7.1 或更新版本；本机直接运行，无额外安装包。
- 推荐窗口化和无边框全屏。独占全屏可能覆盖桌面准星；本软件不使用 Game Bar 叠加层，也不向游戏注入代码。
- CS2 动态 / 分裂准星以静态形状显示；半侧描边以全描边近似。此导入处理与参考项目的静态准星范围一致。
- 屏幕显示参数采用原版的单位和几何规则；不同绘图引擎在抗锯齿边缘可能存在细微差异。
